# Bouncing Balls

Pinch in XR, or click in the desktop simulator, to launch colored balls into
the open world. The app follows XRBlocks' ballpit demo: holding a pinch emits
balls along the controller's forward direction, while Rapier handles gravity
and collisions with the captured depth/world mesh. There is no rendered pit or
container.

Run the example from this directory with:

```sh
npm install
npm run interact
```
